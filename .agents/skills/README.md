# Matt Pocock skills

Source: [mattpocock/skills](https://github.com/mattpocock/skills).
Installed revision: [`d81f3a183412e71a5b1e84ca21bc1a35eea03a60`](https://github.com/mattpocock/skills/tree/d81f3a183412e71a5b1e84ca21bc1a35eea03a60).

All 37 skills are included with their supporting files, including the upstream `misc` and `in-progress` collections. The original files are unchanged and licensed under the [MIT license](LICENSE).

This is a repository-local installation. `.agents/skills` is the canonical copy; `.claude/skills`, `.cursor/skills`, and `.github/skills` are relative symlinks to it. Other agents can discover the collection through the root `AGENTS.md` and read the skill files directly.

Read a skill's `SKILL.md` before using it. Installing a skill does not execute its workflows, install hooks, or configure issue trackers. The upstream `setup-matt-pocock-skills` workflow is available for configuring the engineering skills when needed.
